# 简谱唱名

看数字，听钢琴，选唱名。按 `jianpu_solfege_trainer_requirements_v1_2.md` 实现的本地网页应用，采用 Vite、TypeScript、原生 HTML/CSS 与 Tone.js。当前目录最初只有需求文档，因此此次从空项目实现；没有覆盖已有应用代码或用户历史。

## 启动

需要 Node.js 22.12 或更高版本（开发验证环境：Node.js 26.0.0）。

```sh
npm install
npm run dev
```

打开终端输出的本地地址，默认是 http://127.0.0.1:5173 。服务只监听本机。后续可用 `npm ci` 按锁文件重装依赖。安装完成后，日常使用不需要外网：八份钢琴 MP3 已包含在 `public/audio/piano/`，没有 CDN、外部字体、账户或云端数据请求。

```sh
npm run test          # 领域规则、状态、存储、音频参数和颜色对比度
npm run typecheck
npm run build
npm run test:browser  # 需要已安装 Google Chrome；使用独立临时测试配置
npm run preview      # 预览 dist 构建结果
```

浏览器测试会在独立浏览器上下文中生成测试记录，不写入日常浏览器的真实历史；测试截图位于 `artifacts/screenshots/`。只有重新准备音频资源时才运行 `npm run prepare:audio`，这一步需要联网，正常启动不执行下载。

## 三种流程

- **练习**：默认 21 题，首次选择立即反馈数字、正确唱名和实际音名。可选 7 / 21 / 35 题，可提前结束；首次错误不会因重听或看解释改成正确。
- **考试**：默认 35 题，提交后仅显示“答案已记录”。交卷后展示正确率、完成状态、各数字统计、逐题选择和实际混淆方向。7 题会提示样本少。提前交卷需确认；正确率按正确数 / 已答数计算，未答不算错，零作答显示“—”。
- **强化**：从已交卷考试报告或历史报告中勾选后主动开始，可跳过对照试听。固定沿用来源考试调性，21 题 = 14 道目标项 + 1—7 各一道复习题；14 道按所选混淆组的次数加权，使用最大余数分配。只选 3/4 时，3 和 4 各出现 8 次，其余各 1 次，无同号相邻。三种流程始终都是七个随机排列的唱名选项。

普通练习和考试均为洗牌袋，7 / 21 / 35 题中每个数字分别出现 1 / 3 / 5 次；跨袋不重复相邻数字。强化先有限次随机洗牌，随后使用最大剩余数量的约束排列保证结束。题序与选项顺序分开生成，重听、音量变化和反馈不会重新洗牌。

混淆矩阵按本场考试的真实首次选择生成，不按选项位置统计；例如“看到 3，选成 fa”只记录 3→4，不推断反方向。强化单独保存，来源摘要及选择项独立快照，不修改原考试，也不把不同条件下正确率的差值叫作能力提升。

## 音乐与声音

使用首调唱名：`1 2 3 4 5 6 7 → do re mi fa sol la si`。切换十二个大调只改变实际音高，不改变答案。中央 C 为 C4 / MIDI 60，A4 / MIDI 69 = 440 Hz；各调主音为 MIDI 60—71，大调半音偏移为 `[0, 2, 4, 5, 7, 9, 11]`。F♯ 大调第七级正确显示 E♯5 / MIDI 77。

钢琴是 Alexander Holm 的 Salamander Grand Piano 采样，使用 Tone.js Sampler 和明确的 MIDI→Hz 换算，不是蜂鸣合成器。固定力度，约 0.8 秒持键，0.18 秒释放；快速重听先释放旧声，新声延后 0.2 秒，避免叠加。音量默认 30%，可即时调整或静音。出处、文件校验值和 CC BY 3.0 许可见 `THIRD_PARTY_NOTICES.md` 与音频目录。

浏览器需要用户点击开始或试听来初始化声音。加载时不能作答或计时；失败显示原因和重试操作，也可明确选择“静音继续”。主动静音可在无采样时作答；重新启用声音时先恢复音频。浏览器转入后台或音频意外挂起会暂停，回来后需点击继续：未答题保留原题并重播，但该题耗时记为无效；已答题保留反馈且不能重答。

## 本地记录与迁移

存储键为 `jianpu-solfege-trainer`，结构保持 `schemaVersion: 2`。保存独立设置与最近 100 轮已结束记录，按结束时间排序、session ID 去重。强化来源被淘汰后仍保留来源摘要。清空历史需要确认，仅修改本应用的数据并移除本应用旧版备份，不清除同源其他应用数据。

支持同一键中可识别的 `schemaVersion: 1` 数据：根字段为 `settings` 和 `sessions`；设置包括 key、volume、muted、questionCount（或 practiceQuestionCount），历史包括 id、key、plannedQuestions、endedAt 和 Summary。迁移前保存一份 `jianpu-solfege-trainer:backup` 原始备份；旧轮次均标为普通练习的“旧版摘要记录”，`answers: null`，不猜测错选。考试题数使用默认 35。没有旧版源码可供确认其他历史键或未文档化的格式，因此不扫描或猜测它们。

JSON 损坏、未知版本或备份失败时保留原键，明确提示只在内存中运行。普通写入失败时保留本页内存记录，可重试保存；成功后撤下失败提示。存储按浏览器来源隔离，换域名/端口、清理网站数据、隐私模式可能影响记录。**进行中的轮次刷新后不恢复**；刷新回到首页、不自动发声，已结束记录仍保存。

## 视觉与键盘

设计变量在 `src/styles/tokens.css`，基础样式、控件和页面分别在同目录的 CSS 文件中。浅灰首页/报告、白色答题区、系统字体、单一蓝色强调；绿/红只在练习或强化揭晓答案后出现。大数字是答题页的视觉主角，没有渐变、玻璃、插画、后台导航或奖励动画。

七个选项等尺寸，宽屏一行、低于 768px 四加三排列；320px 不横向溢出。反馈区预留空间，普通反馈不移动下一题。必要操作允许自然纵向滚动，正文不被固定高度裁剪。音量弹层不会改变题面位置，设置页声音展开正常占位，不覆盖开始按钮。

Tab 按 DOM/视觉顺序移动，空格或 Enter 原生激活按钮；没有数字答题捷径或叠加的全局 Enter 处理。新题聚焦数字标题，答案不获得默认焦点。作答后锁定答案，反馈为 polite live region；考试的 DOM 和可访问文本不包含正确解释。弹窗限制焦点在内部，Escape/取消不提交；取消返回触发控件。支持 `prefers-reduced-motion`，题面更新无入场动画。

## 已验证与待验证

2026-09-25 的实际结果：23 项单元测试、15 项 Chrome 浏览器测试、TypeScript 检查及生产构建通过。已检查需求指定的五个视口、键盘流程、文字放大 200%、减少动态效果和页面级横向溢出。Safari 真机通过原生菜单设为 **200% 页面缩放**，实际完成答题、暂停恢复及进入下一题，之后已还原 100%。详细记录及截图索引见 `ACCEPTANCE.md`。

音频自动化验证了本地采样请求、加载错误/恢复、MIDI→Hz 参数、释放调用及主动静音；这些不能证明扬声器音色与无爆音的主观听感。本次未做人工扬声器听验、VoiceOver 完整测试、完整 Safari 功能回归、Playwright WebKit 或真实手机测试，不宣称这些项目已通过。

## 故障排查

- 启动失败：确认 Node 版本，先安装依赖；端口被占用时使用终端实际地址。为了访问原历史，尽量维持相同来源和端口。
- 钢琴采样无法加载：确认本地 `public/audio/piano/` 下八份 MP3 完整；资源缺失时重新运行准备脚本，然后点击重试。浏览器声音权限或系统输出静音需分别检查。
- 数据保存失败：留在页面保留内存记录，检查浏览器存储权限/空间后点击重试。对于未知/损坏版本，原始数据未覆盖，需先备份和核实数据结构再处理，刷新会丢弃内存中的新记录。

源模块各负责一个规则：`music` 音高、`quiz` 洗牌、`session` 首次提交和暂停、`confusion` 方向统计、`reinforcement` 配额、`statistics` 汇总、`storage` 持久化、`audio` 声音、`views/main` 呈现与交互。产品不包含登录、录音、听音猜音、通过线、排名或云服务。

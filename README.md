# 简谱唱名

看数字，听钢琴，选唱名。按 `jianpu_solfege_trainer_requirements_v0.1.2.md` 实现的本地网页应用，采用 Vite、TypeScript、原生 HTML/CSS 与 Tone.js。0.1.2 在原有简谱识读基础上增加相对音程，保留原有音乐规则、强化流程和历史记录。

## Mac 应用

已提供原生 macOS 应用，适用于 **Apple Silicon（M 系列）Mac、macOS 13 或更新版本**：

- `artifacts/macos/简谱唱名.app`
- `artifacts/macos/简谱唱名-0.1.2-macOS-AppleSilicon.zip`

解压 ZIP 后，把“简谱唱名.app”拖到“应用程序”，双击即可运行。钢琴采样、页面和许可均在包内；日常运行不需要 Node.js、终端、开发服务器或外网。当前版本使用本机临时签名（ad hoc），没有 Apple Developer ID 签名或公证；跨设备分发时可能出现来源确认提示。本次未制作 Intel 或 App Store 版本。

Mac 版使用系统 AppKit 窗口和 WKWebView。Tab 可遍历全部按钮，空格 / Enter 选择，⌘+ / ⌘− 调整页面缩放，⌘0 恢复实际大小。切换应用、隐藏或最小化时暂停声音与轮次；回来后点击继续。关闭窗口或 ⌘Q 时，进行中的轮次会提示确认；要保存部分成绩，请先使用页面内的“结束本轮 / 提前交卷”。

设置和最近 100 轮历史独立保存在 Mac 应用的本地存储中，退出重开仍保留。**浏览器已有记录不会自动转入 Mac 版，也不会被改动。** 不要清理应用的本地数据。验收成绩使用独立 bundle ID 的副本保存，没有写入正式应用历史。

维护者可在 Mac 上用 Node.js 和 Apple Command Line Tools 重建，不需要完整 Xcode：

```sh
npm ci
npm run package:mac
npm run test:mac
npm run test:mac -- --network  # 先退出应用；短暂占用本机端口进行服务与冲突测试
```

原生源码在 `native/macos/`，打包与校验脚本在 `scripts/`。内置静态服务只监听 `127.0.0.1:41876`，只读且限制路径在包内，退出后释放端口。固定 bundle ID 与端口用于保持历史的存储来源，不要随意修改；端口被占用会明确报错。源码重建在受限沙箱内运行时，系统 `iconutil` 可能需要沙箱外执行权限，正常终端运行不需要额外配置。

## 网页开发启动

需要 Node.js 22.12 或更高版本（开发验证环境：Node.js 26.0.0）。

```sh
npm install
npm run dev
```

打开终端输出的本地地址，默认是 http://127.0.0.1:5173 。服务只监听本机。后续可用 `npm ci` 按锁文件重装依赖。安装完成后，日常使用不需要外网：八份钢琴 MP3 已包含在 `public/audio/piano/`，没有 CDN、外部字体、账户或云端数据请求。

```sh
npm run test          # 领域规则、状态、存储、音频参数和颜色对比度
npm run typecheck
npm run build
npm run test:browser  # 需要已安装 Google Chrome；使用独立临时测试配置
npm run preview      # 预览 dist 构建结果
```

浏览器测试会在独立浏览器上下文中生成测试记录，不写入日常浏览器的真实历史；测试截图位于 `artifacts/screenshots/`。只有重新准备音频资源时才运行 `npm run prepare:audio`，这一步需要联网，正常启动不执行下载。

## 两个模块

首页先选择 **简谱识读** 或 **相对音程**，每个模块再选择练习或考试；两模块分别保存调性、练习/考试题数，声音偏好共用。默认练习 21 题、考试 35 题，均可选 7 / 21 / 35。

- **简谱识读**：原有数字题面和单音播放保留，数字仍是视觉主角。
- **相对音程**：每题先播放当前调的参考 do，再播放 do–si 之一的目标音，不显示目标数字。参考 do 使用当前调原定主音（C4—B4），不额外降低八度；目标包含同音 do，不含高八度 do。重听播放同一对声音。

听音题在整对声音结束后才开放答案并开始计时。播放中答案、重听与下一题锁定；暂停/结束会取消未发出的目标音，恢复后从参考 do 重播同题。静音或音量为 0 必须明确启用声音才能继续。练习提交后揭晓目标唱名，考试仅中性确认，交卷后再显示逐唱名统计和真实混淆方向；不自动诊断绝对音高或长期听力。

所有模块首次选答后，无论对错都会自动重播当前题一次：简谱播放数字对应单音，相对音程播放参考 do 与目标音。反馈立即呈现，重播完成后可继续下一题；不会播放误选项的音，也不增加手动重听次数。中途暂停后从头重播，保留首次答案与耗时。简谱主动静音时仍可继续。

相对音程本版不新增强化流程，不能进入简谱强化。原有考后强化保留在简谱识读模块。历史按“模块 · 模式 · 调性”区分并可筛选，两模块成绩与速度不合并比较。

需求与视觉方案均已新增 0.1.2 完整版，0.1.0 两份文档保持原始内容（正文旧 v1.2 标识也原样保留）。

## 简谱识读的三种流程

- **练习**：默认 21 题，首次选择立即反馈数字、正确唱名和实际音名。可选 7 / 21 / 35 题，可提前结束；首次错误不会因重听或看解释改成正确。
- **考试**：默认 35 题，提交后仅显示“答案已记录”。交卷后展示正确率、完成状态、各数字统计、逐题选择和实际混淆方向。7 题会提示样本少。提前交卷需确认；正确率按正确数 / 已答数计算，未答不算错，零作答显示“—”。
- **强化**：从已交卷考试报告或历史报告中勾选后主动开始，可跳过对照试听。固定沿用来源考试调性，21 题 = 14 道目标项 + 1—7 各一道复习题；14 道按所选混淆组的次数加权，使用最大余数分配。只选 3/4 时，3 和 4 各出现 8 次，其余各 1 次，无同号相邻。三种流程始终都是七个随机排列的唱名选项。

普通练习和考试均为洗牌袋，7 / 21 / 35 题中每个数字分别出现 1 / 3 / 5 次；跨袋不重复相邻数字。强化先有限次随机洗牌，随后使用最大剩余数量的约束排列保证结束。题序与选项顺序分开生成，重听、音量变化和反馈不会重新洗牌。

混淆矩阵按本场考试的真实首次选择生成，不按选项位置统计；例如“看到 3，选成 fa”只记录 3→4，不推断反方向。强化单独保存，来源摘要及选择项独立快照，不修改原考试，也不把不同条件下正确率的差值叫作能力提升。

## 音乐与声音

使用首调唱名：`1 2 3 4 5 6 7 → do re mi fa sol la si`。切换十二个大调只改变实际音高，不改变答案。中央 C 为 C4 / MIDI 60，A4 / MIDI 69 = 440 Hz；各调主音为 MIDI 60—71，大调半音偏移为 `[0, 2, 4, 5, 7, 9, 11]`。F♯ 大调第七级正确显示 E♯5 / MIDI 77。

钢琴是 Alexander Holm 的 Salamander Grand Piano 采样，使用 Tone.js Sampler 和明确的 MIDI→Hz 换算，不是蜂鸣合成器。固定力度，约 0.8 秒持键，0.18 秒释放；快速重听先释放旧声，新声延后 0.2 秒，避免叠加。音量默认 30%，可即时调整或静音。出处、文件校验值和 CC BY 3.0 许可见 `THIRD_PARTY_NOTICES.md` 与音频目录。

浏览器需要用户点击开始或试听来初始化声音。加载时不能作答或计时；失败显示原因和重试操作。简谱识读还可明确选择“静音继续”。简谱识读主动静音可在无采样时作答；相对音程必须有声音，不能静音继续。重新启用声音时先恢复音频。浏览器转入后台或音频意外挂起会暂停，回来后需点击继续：未答题保留原题并重播，但该题耗时记为无效；已答题保留反馈且不能重答。

## 本地记录与迁移

存储键仍为 `jianpu-solfege-trainer`，本版使用 `schemaVersion: 3`。每轮记录明确 `module: notation | relative` 与 `mode: practice | exam | reinforcement`；两个模块合计保留最近 100 轮，按结束时间排序、ID 去重。强化只属于简谱模块，其来源摘要快照与原考试分离。

从 schema v2 升级时，先把原始字符串备份到 `jianpu-solfege-trainer:backup:v2`，再将旧记录归入简谱识读，保留逐题首次答案、完成状态、计分和强化快照。旧设置进入 `settings.modules.notation`，相对音程从 C / 21 / 35 默认设置开始。音量与静音仍共享。

旧 schema v1 摘要记录继续支持：保留原摘要、标注“旧版摘要记录”，`answers: null`，不猜测具体错选。原 v1 备份键 `jianpu-solfege-trainer:backup` 不会被 v2 迁移覆盖。归档需求文档的 0.1.0 与存储 schema v1/v2 是不同版本体系。

JSON 损坏、未知模块/版本或备份失败时保留原键，明确提示仅在内存中运行；新格式不能覆盖未识别的数据。普通保存失败可重试。清空历史需要确认，仅处理本应用历史及其迁移备份。存储按浏览器来源或 Mac 应用隔离；本版不自动恢复进行中的轮次，刷新/重开回首页，已结束记录保留。

## 视觉与键盘

设计变量在 `src/styles/tokens.css`，基础样式、控件和页面分别在同目录的 CSS 文件中。浅灰首页/报告、白色答题区、系统字体、单一蓝色强调；绿/红只在练习或强化揭晓答案后出现。简谱的大数字是答题页的视觉主角；听音页使用普通状态标题与七项答案，不渲染目标数字，没有渐变、玻璃、插画、后台导航或奖励动画。

七个选项等尺寸，宽屏一行、低于 768px 四加三排列；320px 不横向溢出。反馈区预留空间，普通反馈不移动下一题。必要操作允许自然纵向滚动，正文不被固定高度裁剪。音量弹层不会改变题面位置，设置页声音展开正常占位，不覆盖开始按钮。

Tab 按 DOM/视觉顺序移动，空格或 Enter 原生激活按钮；没有数字答题捷径或叠加的全局 Enter 处理。新题聚焦题目标题（简谱数字或“听音选择唱名”），答案不获得默认焦点。作答后锁定答案，反馈为 polite live region；考试的 DOM 和可访问文本不包含正确解释。弹窗限制焦点在内部，Escape/取消不提交；取消返回触发控件。支持 `prefers-reduced-motion`，题面更新无入场动画。

## 故障排查

- 启动失败：确认 Node 版本，先安装依赖；端口被占用时使用终端实际地址。为了访问原历史，尽量维持相同来源和端口。
- 钢琴采样无法加载：确认本地 `public/audio/piano/` 下八份 MP3 完整；资源缺失时重新运行准备脚本，然后点击重试。浏览器声音权限或系统输出静音需分别检查。
- 数据保存失败：留在页面保留内存记录，检查浏览器存储权限/空间后点击重试。对于未知/损坏版本，原始数据未覆盖，需先备份和核实数据结构再处理，刷新会丢弃内存中的新记录。

源模块各负责一个规则：`music` 音高、`quiz` 洗牌、`session` 首次提交和暂停、`confusion` 方向统计、`reinforcement` 配额、`statistics` 汇总、`storage` 持久化、`audio` 声音、`views/main` 呈现与交互。产品不包含登录、录音、绝对音高测验、通过线、排名或云服务。
